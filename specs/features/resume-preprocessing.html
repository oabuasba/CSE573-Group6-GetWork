Resume preprocessing

Turn the raw IT resume corpus into a clean, labeled, deduplicated table that structuring can read, with an audit log of everything removed.

Status: draftUpdated: 2026-11-07Pipeline step: 1 (resume side)Master: architecture.html
resume-preprocessing

Goal

Step 1 of the pipeline (ADR-2) for the resume side. It reads the 29,783 resumes in data/resume_corpus/resumes_corpus.zip and writes a cleaned table, the untouched raw text, a drop log, and a summary of counts. No LLM is involved. Later steps (llm-structuring, the judges, the app) read these outputs and never the zip, so every quirk of the source (cp1252 encoding, HTML highlight spans, near-duplicate resumes, unlabeled resumes) is handled once, here. All resumes are processed: there is no sampling in this feature.

Input: zip read in place, never extracted
LLM calls: none
Rows: 29,783 in
Expected drops: about 1k (short + duplicates)
Output: data/processed/resumes/, committed

Scope

In scope

  • Minimal Python project scaffold managed with uv (pyproject.toml and a committed uv.lock at the repo root, the src/getwork/ package, tests in src/tests/), because the repo has no code yet.
  • Reading .txt/.lab pairs from the zip, decoding them, and validating labels.
  • Cleaning text, quality filtering (too short, corrupted, non-English), and deduplication with label merging.
  • Writing data/processed/resumes/resumes_clean.parquet, resumes_raw.parquet, resumes_drop_log.csv, and resumes_summary.json.
  • A command-line entry point and tests, including a validation test of the real outputs.

Out of scope

  • Job postings: owned by posting-preprocessing.
  • Skill extraction and the structured record (CC-1): owned by llm-structuring. Handling very long resumes (the longest is about 88k characters) is also its job. This feature only records n_chars and n_words.
  • Stratified dev/test sampling and the "first label" stratification itself: owned by eval-sampling-pooling. This feature only provides first_label.
  • Config loading, the model client wrapper, and shared Pydantic models: owned by project-foundation. The thresholds here live in a dataclass with defaults.
  • resume_samples.zip and its extracted resume_samples.txt (the same resumes in one file, with raw un-normalized occupations): not used.
  • How raw data is committed to git, and the nested .git in data/resume_corpus/: see Q-7. This feature only reads the zip's path.

Design

Load, add cleaned columns, filter, deduplicate, write. Each stage is a pure function on a pandas DataFrame so it can be tested without the real data. The order of drop rules is fixed and the first rule a row fails is the one logged. Raw text is preserved verbatim in a separate file because the judges must read raw text (ADR-9). The 10 occupation labels are the corpus's own normalized classes. This feature relies on ADR-2 (artifacts are the hand-off between phases) and the proposed repo conventions in the master doc's core contracts (Q-6).

# src/getwork/preprocess/text.py
def decode_bytes(data: bytes) -> tuple[str, str]:
    """Return (text, encoding). Try strict UTF-8, then strict cp1252.
    encoding is "utf-8" or "cp1252". Raise ValueError if both fail."""

def clean_text(raw: str) -> str:
    """Remove <span ...> and </span> tags (case-insensitive), apply html.unescape,
    replace "\xa0" with " ", collapse every whitespace run to one space, strip.
    Idempotent on text whose entities decode only once (the tested case); double-escaped
    entities such as "&amp;lt;" decode further on a second pass, so it is not idempotent in general.
    Leaves other tags and all other characters (including "•") alone."""

def alpha_ratio(text: str) -> float:
    """Letters divided by non-whitespace characters. 1.0 if there are none."""

def control_ratio(text: str) -> float:
    """(characters in Unicode category Cc or Co, excluding "\n", "\r", "\t",
    plus U+FFFD) divided by len(text). 0.0 for empty text."""

def detect_language(text: str, sample_chars: int = 2000) -> tuple[str, float]:
    """langdetect on text[:sample_chars] with DetectorFactory.seed = 0.
    Return (top language code, probability).
    Return ("unknown", 0.0) if langdetect raises LangDetectException."""
# src/getwork/preprocess/resumes.py
from pathlib import Path
import pandas as pd

RESUME_CLASSES: frozenset[str] = frozenset({
    "Software_Developer", "Web_Developer", "Systems_Administrator", "Project_manager",
    "Network_Administrator", "Front_End_Developer", "Database_Administrator",
    "Java_Developer", "Security_Analyst", "Python_Developer",
})

def load_resumes(zip_path: Path) -> pd.DataFrame:
    """Read every .txt/.lab pair. Columns: id (str "r-<stem>"), text_raw (str),
    labels (list[str], file order, blank lines skipped, repeats removed keeping first),
    encoding (str). Sorted by id. Ignore zip entries that are directories or not
    .txt/.lab. Raise ValueError if a .txt has no .lab, a .lab has no .txt, or a label
    is not in RESUME_CLASSES."""

def add_clean_columns(df: pd.DataFrame) -> pd.DataFrame:
    """Return a copy with: text_clean (str) = clean_text(text_raw); n_chars (int) =
    len(text_clean); n_words (int) = len(text_clean.split()); first_label (str | None) =
    labels[0] or None; has_label (bool) = len(labels) > 0."""
# src/getwork/preprocess/filters.py
from dataclasses import dataclass

@dataclass(frozen=True)
class ResumeFilterConfig:
    min_words: int = 50
    max_control_ratio: float = 0.01
    min_alpha_ratio: float = 0.5
    non_english_min_prob: float = 0.90
    lang_sample_chars: int = 2000

def apply_quality_filters(df: pd.DataFrame, cfg: ResumeFilterConfig) -> tuple[pd.DataFrame, pd.DataFrame]:
    """Input: output of add_clean_columns. Return (kept, dropped).
    kept: input rows that pass every rule, same columns and row order.
    dropped: columns id (str), rule (str), detail (str), one row per dropped input row.
    Rules, evaluated in this order, first failure wins:
      "too_short":   n_words < cfg.min_words                       detail "n_words=<n>"
      "corrupted":   control_ratio(text_raw) > cfg.max_control_ratio
                     or alpha_ratio(text_clean) < cfg.min_alpha_ratio
                                                                  detail "control_ratio=<x:.4f> alpha_ratio=<y:.4f>"
      "non_english": lang != "en" and prob >= cfg.non_english_min_prob
                     where (lang, prob) = detect_language(text_clean, cfg.lang_sample_chars)
                     ("unknown" is never dropped)                 detail "lang=<code> prob=<p:.2f>"
    """
# src/getwork/preprocess/dedup.py
def drop_duplicates_merge_labels(df: pd.DataFrame) -> tuple[pd.DataFrame, pd.DataFrame]:
    """Input: output of add_clean_columns (or of apply_quality_filters' kept).
    Duplicate key = " ".join(text_clean.casefold().split()). In each group of rows with
    the same key, keep the row with the smallest id (string order). The kept row's
    labels become the ordered union of all group members' labels, in id order, repeats
    removed; first_label and has_label are recomputed. Return (kept, dropped).
    kept: same columns, input row order. dropped: columns id, rule, detail with
    rule "duplicate" and detail "duplicate_of=<kept id>"."""
# src/getwork/preprocess/run_resumes.py
DEFAULT_ZIP: Path = Path("data/resume_corpus/resumes_corpus.zip")
DEFAULT_OUT: Path = Path("data/processed/resumes")

def run(zip_path: Path, out_dir: Path, cfg: ResumeFilterConfig = ResumeFilterConfig()) -> dict:
    """load_resumes -> add_clean_columns -> apply_quality_filters ->
    drop_duplicates_merge_labels -> write the four output files; return the summary dict."""

def main(argv: list[str] | None = None) -> int:
    """CLI: uv run python -m getwork.preprocess.run_resumes [--zip PATH] [--out DIR].
    Prints the summary JSON to stdout. Returns 0."""

Acceptance criteria

Each criterion states an observable behavior and the test that proves it. Ids are stable: append new ones, and mark removed ones with <del> instead of renumbering.

  1. AC-1: After uv sync, uv run python -c "import getwork.preprocess" succeeds and uv run pytest runs the suite. Test: src/tests/test_package.py::test_package_imports
  2. AC-2: decode_bytes returns ("abc", "utf-8") for ASCII/UTF-8 bytes, returns ("• item", "cp1252") for b"\x95 item", and raises ValueError for b"\x81\x8d" (invalid UTF-8, undefined in cp1252). Test: src/tests/test_text.py::test_decode_utf8, ::test_decode_cp1252, ::test_decode_invalid_raises
  3. AC-3: clean_text removes <span class="hl"> and </SPAN> but leaves <div> intact, unescapes &amp; and &nbsp;, turns \xa0 into a space, collapses whitespace, keeps •, and is idempotent on its own output for ordinary text (a second pass changes nothing; not guaranteed for double-escaped entities such as &amp;lt;, which decode one more level). Test: src/tests/test_text.py::test_clean_text_strips_spans_only, ::test_clean_text_entities_and_whitespace, ::test_clean_text_idempotent
  4. AC-4: alpha_ratio and control_ratio return the documented values on hand-computed examples, including empty text. Test: src/tests/test_text.py::test_alpha_ratio, ::test_control_ratio

Assumptions

1. The Q-6 conventions (Python 3.11+, pytest, Parquet) are adopted for this feature, though the user has not confirmed them explicitly. The layout follows the user's tree: all code under src/ (package src/getwork/, tests in src/tests/), with only pyproject.toml at the repo root, which is an assumption because uv and pytest look for it there. uv is the package manager, as the user decided. The top-level evaluations/ directory is not used by this feature. 2. langdetect (seeded) is the language library. The user asked for a Python library and allowed pandas. lingua is more accurate but heavier; swapping means changing only detect_language. 3. Thresholds (min_words=50, alpha ratio 0.5, control ratio 0.01, language probability 0.90) are provisional. The first three come from the measurements above; the language threshold is unmeasured because langdetect is not installed yet. Inspect the drop log after the first real run. 4. first_label is labels[0]. Whether the order of labels in a .lab file carries meaning is not verified. 5. Cleaned outputs are committed under data/processed/resumes/ as the user decided; the raw zip is not touched by this feature (Q-7 is still open). 6. Whitespace is flattened completely. The source has no newlines, so no structure is lost.

embedding-client

One EmbeddingClient protocol with a local Qwen3-Embedding-4B backend (sentence-transformers, the default), an optional Voyager backend, and an offline fake. Shared by skill embedding (step 3) and document embedding (step 6).

Status: draftUpdated: 2026-11-07Pipeline step: 3 and 6 (shared)Master: architecture.html
embedding-client

Goal

Two stages need vectors: skill-taxonomy embeds up to 1,000 single skills, and document-embedding embeds every serialized document twice (Full and B2). ADR-4 fixes the model (Qwen3-Embedding-4B through sentence-transformers); the user runs it locally on an RTX 5070 (12 GB), and ASU Voyager also serves qwen3-embedding-4b and 8b. This feature adds the seam both stages call, mirroring LLMClient/FakeLLMClient (ADR-14): an EmbeddingClient protocol, a deterministic FakeEmbeddingClient so tests never load a model or touch the network, the local sentence-transformers client (GPU, with out-of-memory batch backoff), an optional Voyager client, backend selection and validation, a resumable chunk cache, and the row-aligned .npy vector files that carry the embedding provenance (model, backend, dimension) so vectors from different backends are never mixed. The first Hugging Face model download and every GPU run are user-run checklist steps. The 8B model is out of scope unless the 4B clusters poorly (follow-up).

Scope

In scope

  • src/getwork/embed/: protocol and errors (client.py), fake (fake.py), OOM-aware batching (batching.py), chunk cache (cache.py), vector files (store.py), settings and factory (settings.py, factory.py), local client (st_client.py), Voyager client (voyager_embed.py), and the embed-preflight command.
  • An optional dependency group embed (sentence-transformers, torch) so the offline test suite never needs them; numpy becomes a core dependency.
  • Runbook and user-run checklist EU-1 to EU-6.

Out of scope

  • Downloading the model, installing the embed extra, and any GPU run: user-run only.
  • Qwen3-Embedding-8B and query-time hosting (Q-1). Both are follow-ups; the protocol makes them a config change.
  • What text is embedded (skill strings: skill-taxonomy; documents: document-embedding) and any vector math beyond normalization.
  • Instruction prefixes and Matryoshka dimension truncation (decision E-4).

Design

Stages call client.embed(texts) and get unit-length float32 rows (CC-5); client.info describes the model for provenance. Which implementation is behind it is a flag or variable (CC-13). Tests inject FakeEmbeddingClient. Cites ADR-4, ADR-12, ADR-14, CC-10, CC-11, CC-13. Requires alias-table T-1 and T-2 (pyproject.toml sequencing, fileio) and local-llm-backend T-2 (_validate_base_url with a name argument).

# src/getwork/embed/client.py   (numpy only; no torch, no openai)
EMBEDDING_BACKENDS: tuple[str, ...] = ("local", "voyager")

@dataclass(frozen=True)
class EmbeddingInfo:
    model: str
    backend: str                       # "local" | "voyager" | "fake"
    dim: int
    max_seq_length: int | None = None
    dtype: str | None = None           # "float16", "float32", ... or None
    def as_dict(self) -> dict[str, object]:
        """The five fields as a dict, keys in the order model, backend, dim, max_seq_length, dtype."""

class EmbeddingError(Exception): ...
class EmbeddingResourceError(EmbeddingError): ...   # out of memory even at batch size 1
class EmbeddingMismatchError(EmbeddingError): ...   # vector sets from different model/backend/dim

class EmbeddingClient(Protocol):
    @property
    def info(self) -> EmbeddingInfo: ...
    def embed(self, texts: Sequence[str]) -> np.ndarray:
        """float32 array (len(texts), info.dim); row i embeds texts[i]; every row has L2 norm within 1e-3 of 1.
        Empty input returns shape (0, info.dim). Raises EmbeddingError (HTTP backends may also raise the
        getwork.llm.client.LLMError subclasses)."""

def l2_normalize(vectors: np.ndarray) -> np.ndarray:
    """float32 copy with each row divided by its L2 norm. EmbeddingError if the array is not 2-D, a value is not
    finite, or a row norm is below 1e-12."""

# src/getwork/embed/fake.py
class FakeEmbeddingClient:
    def __init__(self, dim: int = 64, model: str = "fake-embedding") -> None: ...
    calls: list[list[str]]             # texts of every embed() call, in order
    @property
    def info(self) -> EmbeddingInfo: ...        # EmbeddingInfo(model, "fake", dim)
    def embed(self, texts: Sequence[str]) -> np.ndarray:
        """Deterministic, process-independent bag-of-words vectors. tokens = re.findall(r"\w+", text.casefold());
        no tokens -> the single token "\x00". token_vector(t): bytes = b"".join(sha256(f"{i}:{t}".encode()).digest()
        for i in range(ceil(dim/32)))[:dim]; value = byte - 127.5 as float32. A text's vector is the sum of its
        token vectors (a repeated token counts each time), then l2_normalize. Appends list(texts) to calls."""

# src/getwork/embed/batching.py   (no torch)
def encode_in_batches(encode: Callable[[Sequence[str]], np.ndarray], texts: Sequence[str], batch_size: int, *,
                      is_oom: Callable[[BaseException], bool],
                      on_oom: Callable[[int], None] | None = None) -> np.ndarray:
    """ValueError if texts is empty or batch_size < 1. Order texts by (-len(text), index); take consecutive slices
    of the current batch_size; encode(slice) returns (len(slice), dim). When encode raises an exception with
    is_oom(exc) true: if batch_size == 1 raise EmbeddingResourceError("out of memory at batch size 1");
    otherwise batch_size = max(1, batch_size // 2), call on_oom(new batch_size), retry the same slice. Other
    exceptions propagate unchanged. The reduced batch size stays for later slices. Return the rows in the
    original input order as float32."""

# src/getwork/embed/cache.py   (uses getwork.fileio.atomic_write)
def embed_cached(client: EmbeddingClient, texts: Sequence[str], *, cache_dir: Path | None, chunk_size: int = 256,
                 progress: Callable[[int, int], None] | None = None) -> np.ndarray:
    """ValueError if chunk_size < 1. Chunks are consecutive slices of chunk_size. Chunk i has
    key = sha256(json.dumps([client.info.as_dict(), list(chunk_texts)], ensure_ascii=False, sort_keys=True)
    .encode("utf-8")).hexdigest()[:16] and file cache_dir / f"chunk_{i:06d}_{key}.npy". An existing file with shape
    (len(chunk), info.dim) is loaded; otherwise client.embed(chunk) is saved through atomic_write (np.save to an
    open file object) and used. cache_dir None disables caching. Other files in cache_dir are never deleted.
    progress(done_chunks, total_chunks) is called after each chunk. Returns the rows in order;
    no texts -> np.zeros((0, info.dim), np.float32)."""

    meta["embedding"] is a dict whose "dim" equals vectors.shape[1]."""
def read_vectors(directory: Path, stem: str) -> VectorSet:
    """FileNotFoundError naming the missing path. ValueError if the three files disagree (row count, dim,
    ids not unique)."""
def check_same_embedding(a: Mapping[str, object], b: Mapping[str, object]) -> None:
    """a and b are meta dicts. Compare meta["embedding"]["model"], ["backend"], ["dim"]; raise

@dataclass(frozen=True)
class EmbedSettings:
    backend: str                       # one of EMBEDDING_BACKENDS
    model: str
    device: str = "auto"               # local only: "auto", "cpu", "cuda", "cuda:N"
    dtype: str = "auto"                # local only: "auto", "float16", "bfloat16", "float32"

    max_seq_length: int = DEFAULT_MAX_SEQ_LENGTH
    api_key: str = field(default="", repr=False)   # voyager only
    base_url: str = ""                 # voyager only
    def __str__(self) -> str:          # "EmbedSettings(backend=..., model=..., device=..., batch_size=...)", never the key

def load_embed_settings(environ: Mapping[str, str], dotenv_path: Path | None, *,
                        backend: str | None = None, model: str | None = None, device: str | None = None,
                        dtype: str | None = None, batch_size: int | None = None,
                        max_seq_length: int | None = None) -> EmbedSettings:
    """Values from dotenv_values (if the file exists) overlaid by environ; blank counts as missing; os.environ is

class SentenceTransformerClient:

        """Import torch and sentence_transformers here; ImportError -> EmbeddingError("sentence-transformers and
        torch are not installed; run: uv sync --extra embed"). device "auto": "cuda" if torch.cuda.is_available()
        else EmbeddingError("no CUDA device found; pass --device cpu to run on the CPU (very slow for a 4B model)").
        dtype "auto": "float16" on a cuda device, "float32" on cpu; torch_dtype = getattr(torch, dtype_name).
        self._model = SentenceTransformer(settings.model, device=device, model_kwargs={"torch_dtype": torch_dtype},
        tokenizer_kwargs={"padding_side": "left"}); self._model.max_seq_length = settings.max_seq_length.
        info = EmbeddingInfo(settings.model, "local", self._model.get_sentence_embedding_dimension(),
        settings.max_seq_length, dtype_name)."""
    @property
    def info(self) -> EmbeddingInfo: ...
    def embed(self, texts: Sequence[str]) -> np.ndarray:
        """Empty -> zeros((0, dim)). Else l2_normalize(encode_in_batches(self._encode, texts, settings.batch_size,

        normalize_embeddings=True, convert_to_numpy=True, show_progress_bar=False). is_oom: isinstance(exc,
        torch.cuda.OutOfMemoryError) or "out of memory" in str(exc).lower(). on_oom(size): torch.cuda.empty_cache()
        when the device starts with "cuda" and one line to stderr naming the new batch size. Any other exception
        becomes EmbeddingError(f"{type(exc).__name__}: {exc}")."""

Data flow

Caller (a stage CLI) calls add_embed_args, then make_embedding_client(args=..., environ=os.environ, client=injected). The stage calls embed_cached(bundle.client, texts, cache_dir=..., chunk_size=...), then write_vectors(dir, stem, ids, vectors, meta={"embedding": bundle.info.as_dict(), ...}). A consuming stage calls read_vectors and check_same_embedding before it combines two vector sets. Output of this feature is code only; the vector files are written by the stages (skill-taxonomy, document-embedding) under artifacts_trial/ (CC-11).

def encode_in_batches(encode: Callable[[Sequence[str]], np.ndarray], texts: Sequence[str], batch_size: int, *,
                      is_oom: Callable[[BaseException], bool],
                      on_oom: Callable[[int], None] | None = None) -> np.ndarray:
    """ValueError if texts is empty or batch_size < 1. Order texts by (-len(text), index); take consecutive slices
    of the current batch_size; encode(slice) returns (len(slice), dim). When encode raises an exception with
    is_oom(exc) true: if batch_size == 1 raise EmbeddingResourceError("out of memory at batch size 1");
    otherwise batch_size = max(1, batch_size // 2), call on_oom(new batch_size), retry the same slice. Other
    exceptions propagate unchanged. The reduced batch size stays for later slices. Return the rows in the
    original input order as float32."""

# src/getwork/embed/cache.py   (uses getwork.fileio.atomic_write)
def embed_cached(client: EmbeddingClient, texts: Sequence[str], *, cache_dir: Path | None, chunk_size: int = 256,
                 progress: Callable[[int, int], None] | None = None) -> np.ndarray:
    """ValueError if chunk_size < 1. Chunks are consecutive slices of chunk_size. Chunk i has
    key = sha256(json.dumps([client.info.as_dict(), list(chunk_texts)], ensure_ascii=False, sort_keys=True)
    .encode("utf-8")).hexdigest()[:16] and file cache_dir / f"chunk_{i:06d}_{key}.npy". An existing file with shape
    (len(chunk), info.dim) is loaded; otherwise client.embed(chunk) is saved through atomic_write (np.save to an
    open file object) and used. cache_dir None disables caching. Other files in cache_dir are never deleted.
    progress(done_chunks, total_chunks) is called after each chunk. Returns the rows in order;
    no texts -> np.zeros((0, info.dim), np.float32)."""

Open questions

Assumptions and facts to confirm
  • Assumed: no instruction prefix for any text (E-4). If Qwen3-Embedding performs better with a task instruction on both sides, that is a later experiment and would change FORMAT_VERSION in document-embedding.
  • Assumed (inferred, not looked up): Qwen3-Embedding-4B produces 2560-dimensional vectors, needs about 8 GB in half precision, loads in sentence-transformers with padding_side="left" and torch_dtype, and the RTX 5070 needs a CUDA 12.8 or newer PyTorch build. Defaults of batch 8 and max_seq_length 2048 are starting points to measure (EU-4).
  • Assumed: Voyager exposes the OpenAI /v1/embeddings route for its Qwen3-Embedding models and accepts a list input of the batch size used (32). Unverified.
  • Decided here, not asked: E-1 to E-9, in particular local-by-default (user decision), no silent CPU fallback (E-5), and the per-backend model variables (E-2).
  • Follow-up: Qwen3-Embedding-8B (local would not fit 12 GB in half precision; Voyager could serve it) only if the 4B taxonomy clusters poorly; it needs no code change, only --embed-model and a new full run.

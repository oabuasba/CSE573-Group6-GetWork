cluster-relabeling

Pipeline step 5: give every document skill a cluster by direct taxonomy lookup, send unseen skills and incomplete documents to an optional LLM fallback, and write the relabeled records (the final skill sets) that document embedding and retrieval use.

Status: draftUpdated: 2026-11-07Pipeline step: 5Master: architecture.html
cluster-relabeling

Goal

The taxonomy (skill-taxonomy) covers only the top 1,000 skills; most documents also list skills outside it, and some documents were extracted poorly. Step 5 turns each canonical record into a relabeled record (CC-15): every skill carries a cluster name (Other for noise and for skills nothing fits), and the record's skills list becomes the final skill set that the Full and B2 serializations (CC-4) and the B1+ Jaccard use. Known skills are assigned by lookup with no model call. Optionally (--use-llm, user-run) an LLM assigns each distinct unseen skill to an existing cluster or Other using the cluster names and example members as few-shot guidance, and re-reads the raw text of documents whose extraction looks incomplete (fewer skills than the 10th percentile of their corpus, or fewer than half of their skills in the taxonomy) to add skills that are stated or implied. All LLM answers are cached and stamped so an interrupted run resumes and runs from different models are never mixed. Without --use-llm the stage is deterministic, free, and runs offline; it still flags the incomplete documents. Defaults point at the trial tree; the trial's low taxonomy coverage means many trial documents are flagged, which is expected.

Scope

In scope

  • getwork.relabel: lookup and completeness rules, the stamped cache, the unseen-skill and re-extraction LLM steps with their prompts, the LLMRelabeler that combines them, relabeled record building and output files, and the relabel command with a runbook and user-run checklist.
  • Reading raw text from data/processed/<source>/<source>_clean.parquet (read only) for re-extraction.

Out of scope

  • Serialization, level, and vectors (document-embedding).
  • Any real LLM call: tests use FakeLLMClient; the LLM run is user-run.
  • Changing the taxonomy (unseen skills are never added to it) or the structured records.
  • Query-time use on new documents (the same functions apply; wiring is a later app feature, Q-1).

Design

One pass over the canonical records per source: split each document's skills into known and unseen, compute the completeness reason, resolve unseen skills (default Other, or through the LLM), optionally re-extract, and write the relabeled records. The LLM parts hide behind a small Relabeler protocol so relabel_source is testable with a hand-written fake. Cites ADR-5, ADR-12, ADR-13, CC-2, CC-3, CC-10, CC-11, CC-14, CC-15. Requires alias-table (T-3, T-4, T-6), skill-taxonomy T-2 (Taxonomy), and local-llm-backend T-1 and T-3.

RL-3Completeness (from the pass-1 canonical skills, before any LLM): no_skills if the list is empty; few_skills if len(skills) < p10 where p10 is the 10th percentile (method "lower") of the skill counts of the same source; low_coverage if the share of skills known to the taxonomy is below 0.5 (--min-known); first match in that order, else none. Noise skills count as known.Matches the architecture's rule. Per-source percentiles because postings list about a third as many skills as resumes; a joint 10th percentile would flag almost only postings. The wording "corpus" is ambiguous, so this is recorded as an assumption.A joint percentile; counting noise skills as unknown (they are in the taxonomy).
RL-4Unseen skills are resolved once per distinct skill (keyed by normalize_key), in batches of 50, with a prompt that lists every cluster name with its first 5 members and asks for exactly one cluster or Other per skill. Answers are validated (each skill exactly once, cluster from the allowed set) with feedback retries, and cached.Few-shot examples per the proposal; per-skill caching makes the cost proportional to distinct skills (a few thousand), not documents.One call per document; free-text cluster answers.
RL-5Re-extraction sends the cleaned text (cut to --max-input-chars, default 48000), the known skills, and the cluster names, and asks for additional skills with a cluster each (at most 50). New skills pass through the alias table (CC-2), duplicates of existing skills (by key) are dropped, a skill the taxonomy knows takes the taxonomy's cluster (RL-1), others keep the model's cluster with via: "llm". The final skills are the pass-1 skills followed by the added ones.The proposal: reprocess from raw text to catch implied skills; adding only (never removing) keeps pass-1 results auditable. added_skills records exactly what changed.Re-running the whole structuring prompt (a second schema); replacing pass-1 skills.
RL-6Two caches under relabeled/_cache/: unseen_assignments.json and reextract.json. Each entry carries taxonomy_version, model, backend, and prompt_version. Entries from another taxonomy version are dropped (counted); entries from another model, backend, or prompt version raise RelabelProvenanceError unless --allow-mixed. The cache is saved after every batch and every document.Resumable runs, and one model for the whole dataset (the same rule as the structurer's ProvenanceMismatchError, extended across backends by ADR-13).No cache; silently mixing models.
RL-7Failures degrade, not abort: a failed unseen batch leaves its skills at Other with via: "default" (retried next run because they are not cached); a failed re-extraction leaves the document unchanged and is listed in <source>_relabel_failures.csv; the exit code is 1. A fatal LLM error (connection refused, 401) stops the run with exit 3 after saving the caches.Same policy as the structurer: per-item failures are data, fatal errors stop.Failing the whole run on one bad reply.
RL-8Records carry the alias table version and the taxonomy version; the stage refuses input whose alias_table_version differs from the table file or from taxonomy.alias_table_version.CC-2 (one table for everything) and the trial/full-corpus separation.Trusting file locations.

class SkillAssignment:

    """int(np.percentile(counts, pct, method="lower")). ValueError for no counts."""
def incomplete_reason(n_skills: int, known: float | None, p10: int, min_known: float = 0.5) -> str | None:

class RelabelProvenanceError(RuntimeError): ...
@dataclass(frozen=True)
class Stamp:
    taxonomy_version: str
    model: str
    backend: str
    prompt_version: str
class StampedCache:
    ignored: int                       # entries dropped at load because their taxonomy_version differs
    def __init__(self, path: Path, stamp: Stamp, *, allow_mixed: bool = False) -> None:
        """Loads path if it exists: {"entries": {key: {"value": ..., "taxonomy_version", "model", "backend",
        "prompt_version"}}}. Entries with another taxonomy_version are dropped (ignored += 1). An entry whose
        model, backend or prompt_version differs from stamp raises RelabelProvenanceError (message names the
        differing fields and values, not keys) unless allow_mixed. A corrupt file raises ValueError naming the path."""
    def get(self, key: str) -> object | None: ...
    def put(self, key: str, value: object) -> None: ...     # stores value with the current stamp
    def save(self) -> None: ...                             # write_json_atomic of the entries; parent dirs created

# src/getwork/relabel/unseen.py
UNSEEN_PROMPT_VERSION: str = "unseen_v1"         # file stem of prompts/unseen_v1.md
EXAMPLES_PER_CLUSTER: int = 5
def load_unseen_prompt(version: str = UNSEEN_PROMPT_VERSION) -> str: ...   # functools.cache; FileNotFoundError if absent
def build_unseen_message(batch: Sequence[str], tax: Taxonomy) -> str:
    """"CLUSTERS:\n" + one line "- {name}: {first 5 members joined by ', '}" per cluster in id order +
    "\n\nSKILLS:\n" + "\n".join("- " + s for s in batch)."""
def parse_assignments(text: str, batch: Sequence[str], valid_names: Collection[str]) -> dict[str, str]:
    """llm.validated.parse_json_object; key "assignments" must be a list of objects with string "skill" and
    "cluster". Every batch skill exactly once, no other skill, cluster in valid_names or OTHER; otherwise
    ValueError with a one-line reason (skill text cut to 60 characters). Returns {skill: cluster}."""
@dataclass(frozen=True)
class UnseenConfig:
    model: str
    backend: str = "voyager"
    batch_size: int = 50
    max_tokens: int = 2048
    max_validation_attempts: int = 3
    extra_body: Mapping[str, object] | None = None
    retry: RetryConfig = RetryConfig()
@dataclass
class UnseenResult:
    assignments: dict[str, str]        # skill (as given) -> cluster, for every skill that was resolved
    failed: list[str]                  # skills of failed batches
    stats: CallStats
def assign_unseen(client: LLMClient, cfg: UnseenConfig, skills: Sequence[str], tax: Taxonomy, cache: StampedCache, *,
                  secrets: Sequence[str] = (), sleep: Callable[[float], None] = time.sleep) -> UnseenResult:
    """Distinct skills by normalize_key (first spelling wins), sorted by key. Cached ones (cache key
    normalize_key) are answered from the cache; the rest go in batches of cfg.batch_size, each as one request
    (temperature 0, reasoning_effort None, response_schema None, extra_body from cfg, system text
    load_unseen_prompt(), user text build_unseen_message) through llm.validated.complete_validated. After each
    successful batch the answers are put in the cache and cache.save() is called. ValidationExhausted,
    RetriesExhausted and PermanentLLMError put the batch's skills in failed and continue; FatalLLMError
    propagates (after cache.save()). Every input skill whose key was resolved appears in assignments under the
    spelling it was given."""

# src/getwork/relabel/reextract.py
REEXTRACT_PROMPT_VERSION: str = "reextract_v1"   # file stem of prompts/reextract_v1.md
MAX_ADDED_SKILLS: int = 50
def load_reextract_prompt(version: str = REEXTRACT_PROMPT_VERSION) -> str: ...
def build_reextract_message(text: str, skills: Sequence[str], tax: Taxonomy, max_chars: int) -> str:
    """"CLUSTERS:\n" + "- {name}" per cluster in id order + "\n\nKNOWN SKILLS:\n" + "- {skill}" lines (or "- (none)")
    + "\n\nTEXT:\n" + text[:max_chars]."""
def parse_reextract(text: str, valid_names: Collection[str]) -> list[tuple[str, str]]:
    """parse_json_object; key "additional_skills" must be a list (possibly empty) of at most MAX_ADDED_SKILLS
    objects with string "skill" (stripped, 1 to 100 characters) and "cluster" (in valid_names or OTHER); skills
    equal ignoring case keep only the first; else ValueError with a one-line reason. Returns [(skill, cluster)]."""
@dataclass(frozen=True)
class ReextractConfig:
    model: str
    backend: str = "voyager"
    max_input_chars: int = 48000
    max_tokens: int = 2048
    max_validation_attempts: int = 3
    extra_body: Mapping[str, object] | None = None
    retry: RetryConfig = RetryConfig()
def reextract_document(client: LLMClient, cfg: ReextractConfig, doc_id: str, text: str, skills: Sequence[str],
                       tax: Taxonomy, cache: StampedCache, stats: CallStats, *, secrets: Sequence[str] = (),
                       sleep: Callable[[float], None] = time.sleep) -> list[tuple[str, str]] | None:
    """cache key f"{doc_id}:{sha256(text[:cfg.max_input_chars].encode('utf-8')).hexdigest()[:12]}"; a cached value
    ([[skill, cluster], ...]) is returned without a call. Otherwise one request (as in assign_unseen; system
    text load_reextract_prompt(), user text build_reextract_message) through complete_validated; on success the
    result is cached and cache.save() called. ValidationExhausted, RetriesExhausted, PermanentLLMError -> None;
    FatalLLMError propagates."""

# src/getwork/relabel/llm_relabeler.py
class Relabeler(Protocol):
    mode: str                          # "llm"
    model: str | None
    backend: str | None
    prompt_version: str | None
    def assign_unseen(self, skills: Sequence[str]) -> Mapping[str, str]: ...      # skill -> cluster; unresolved skills absent
    def reextract(self, doc_id: str, text: str, skills: Sequence[str]) -> list[tuple[str, str]] | None: ...
class LLMRelabeler:
    mode = "llm"
    def __init__(self, client: LLMClient, tax: Taxonomy, *, model: str, backend: str, cache_dir: Path,
                 batch_size: int = 50, max_input_chars: int = 48000, extra_body: Mapping[str, object] | None = None,
                 retry: RetryConfig = RetryConfig(), secrets: Sequence[str] = (), allow_mixed: bool = False,
                 sleep: Callable[[float], None] = time.sleep) -> None:
        """model, backend; prompt_version = f"{UNSEEN_PROMPT_VERSION}+{REEXTRACT_PROMPT_VERSION}". Creates
        StampedCache(cache_dir / "unseen_assignments.json", Stamp(tax.version, model, backend, UNSEEN_PROMPT_VERSION))
        and StampedCache(cache_dir / "reextract.json", Stamp(tax.version, model, backend,
        REEXTRACT_PROMPT_VERSION)); stats = CallStats() shared by both steps."""
    stats: CallStats
    failed_skills: list[str]           # accumulated failed unseen skills
    def assign_unseen(self, skills: Sequence[str]) -> Mapping[str, str]: ...    # assign_unseen(...).assignments; extends failed_skills
    def reextract(self, doc_id: str, text: str, skills: Sequence[str]) -> list[tuple[str, str]] | None: ...

RELABEL_KEYS: tuple[str, ...] = (*CANONICAL_KEYS, "added_skills", "skill_clusters", "incomplete_reason",
                                 "reextracted", "relabel_mode", "taxonomy_version", "relabel_model",
                                 "relabel_backend", "relabel_prompt_version")
RELABEL_PARQUET_SCHEMA: pa.Schema   # CANONICAL_PARQUET_SCHEMA fields, then added_skills list<string>,
                                    # skill_clusters list<struct<skill string, cluster string, via string>>,
                                    # incomplete_reason string, reextracted bool, relabel_mode string,
                                    # taxonomy_version string, relabel_model string, relabel_backend string,
                                    # relabel_prompt_version string
def build_relabel_record(record: Mapping[str, object], assignments: Sequence[SkillAssignment],
                         added_skills: Sequence[str], incomplete: str | None, reextracted: bool, tax: Taxonomy,
                         relabeler: Relabeler | None) -> dict:
    """A new dict with keys in RELABEL_KEYS order: the canonical values of record, except skills =
    [a.skill for a in assignments] (the final skill set); added_skills = list(added_skills);
    skill_clusters = [{"skill", "cluster", "via"} per assignment, same order]; incomplete_reason = incomplete;
    reextracted; relabel_mode = "llm" if relabeler else "lookup_only"; taxonomy_version = tax.version;
    relabel_model / relabel_backend / relabel_prompt_version from relabeler, or None. Never mutates record."""
def relabel_source(source: str, records: Mapping[str, dict], tax: Taxonomy, table: AliasTable,
                   get_text: Callable[[str], str | None], relabeler: Relabeler | None, out_dir: Path, *,
                   min_known: float = 0.5) -> dict:
    """Process records in numeric id order (getwork.structure.inputs.sort_ids).
    1. ValueError if any record's alias_table_version != table.version or table.version != tax.alias_table_version.
    2. p10 = percentile_threshold of len(record["skills"]) over the source; per record split_known, known_fraction,
       incomplete_reason (RL-3).
    3. Unseen skills: if relabeler, call relabeler.assign_unseen once with the distinct unseen skills (by
       normalize_key, sorted by key); a skill it resolves gets via "llm"; every other unseen skill gets OTHER with
       via "default".
    4. If relabeler and the record is incomplete: text = get_text(id); None -> failure stage "no_text";
       else added = relabeler.reextract(id, text, current skills); None -> failure stage "reextract". For each
       (skill, cluster) in added: s = table.canonical(skill) (None -> skip); skip when normalize_key(s) is already
       among the record's skills; if tax.lookup(s) is not None the assignment comes from the taxonomy (RL-1) else
       cluster with via "llm". reextracted = True when the call returned a list (even an empty one).
    5. build_relabel_record for each record; write out_dir/f"{source}_relabeled.jsonl" (RELABEL_KEYS order),
       f"{source}_relabeled.parquet" (RELABEL_PARQUET_SCHEMA, zstd), f"{source}_relabeled_summary.json" and
       f"{source}_relabel_failures.csv" (header id,stage,message), all through fileio, sorted by numeric id.
    Returns the summary: {"source", "relabel_mode", "taxonomy_version", "alias_table_version", "n_records",
    "p10_threshold", "n_incomplete", "incomplete_by_reason": {"no_skills", "few_skills", "low_coverage"},
    "n_reextracted", "n_reextract_failed", "n_skills_final", "via_counts": {"taxonomy", "noise", "llm",
    "default"}, "n_unseen_distinct", "n_unseen_unresolved", "mean_known_fraction", "relabel_model",
    "relabel_backend", "relabel_prompt_version"}  (mean over records with at least one skill, 0.0 if none;
    n_unseen_unresolved counts distinct unseen skills left at "default" in LLM mode, 0 in lookup-only mode)."""
def relabeled_path(root: Path, source: str) -> Path:
    """paths.relabeled_dir(root, source) / f"{source}_relabeled.jsonl"."""
def read_relabeled(root: Path, source: str) -> dict[str, dict]:
    """read_checkpoint(relabeled_path(...), repair=False); FileNotFoundError naming the path (hint: run relabel);
    ValueError naming the id if a record lacks any RELABEL_KEYS key. Records in numeric id order."""

Command and outputs

relabel [--source resumes|postings|both] [--artifacts-dir artifacts_trial] [--processed-dir data/processed] [--use-llm] [--min-known 0.5] [--max-input-chars 48000] [--unseen-batch-size 50] [--allow-mixed] plus the shared LLM options (--backend --model --env-file --extra-body, from add_llm_args) which matter only with --use-llm. Default source is both (resumes first).

  • Reads (never writes): alias/alias_table.json, taxonomy/taxonomy.json, canonical/<source>/<source>_canonical.jsonl, and with --use-llm the text_clean column of <processed-dir>/<source>/<source>_clean.parquet (loaded on the first incomplete document).
  • Writes per source under relabeled/<source>/: <source>_relabeled.jsonl, .parquet, _summary.json, <source>_relabel_failures.csv; with --use-llm also relabeled/_cache/unseen_assignments.json and reextract.json. Rerunning with the same inputs (and a warm cache) gives byte-identical output files.
  • Config errors (LLM settings with --use-llm), missing inputs, and version mismatches are exit 2 before any output directory is created.
  • A relabeled record has all canonical fields plus the CC-15 fields; skill_clusters[i].cluster is the name used by the Full serialization; skills is the final skill set.

class RelabelProvenanceError(RuntimeError): ...

class Stamp:

    model: str
    backend: str
    prompt_version: str
class StampedCache:
    ignored: int                       # entries dropped at load because their taxonomy_version differs

        """Loads path if it exists: {"entries": {key: {"value": ..., "taxonomy_version", "model", "backend",
